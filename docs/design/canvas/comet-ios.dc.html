COMET-BOARD · IOS · REDESIGN
The phone, brought level
Theme.swift is a direct port of theme.rs — the same greys, the same five status hues, the same opacity multipliers — and it is always dark, with no light variant to invert. It also adds a violet family for inline code and three syntax tones, so the phone carries nine hues where the system needs four. Same four greys, same status ramp and the same three radii land here, and light mode arrives for the first time.
Washes drifted from the desktop
iOS uses 0.06 hover and 0.10 active where the desktop uses 0.14 and 0.16. Two ports of one file already disagree about how loud a selection is.
The row splits, the order holds
393pt cannot hold id, title, space, fact and a verb on one line. The desktop's two columns become a fixed meta line under the title — same fields, same order, still a column you can scan.
Review is the phone's best screen
Claims and effects read fine in a narrow column; a diff never does. The surface that stopped being about code is the one that ports to a phone without apology.
